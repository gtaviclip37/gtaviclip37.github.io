klipy-upload – Privacy Policy

Effective date: 18 November 2026 · Website: https://gtaviclip37.github.io/

klipy-upload is a private desktop tool used only by its owner to upload his own edited short videos to his own YouTube channel (and his own Instagram and TikTok accounts). It is not offered to any other users.

Use of YouTube API Services

  • This tool uses YouTube API Services (YouTube Data API v3).
  • By using this tool you agree to be bound by the YouTube Terms of Service.
  • Google's handling of data is described in the Google Privacy Policy.

What information is accessed

  • Basic information about the owner's own YouTube channel (channel ID and title) via channels.list (mine=true).
  • Permission to upload videos selected by the owner via videos.insert.
  • No information about any other YouTube users, viewers or channels is accessed, collected or stored.

How information is used

  • Only to upload the owner's videos (title, description, tags, privacy status) after he explicitly approves each upload, and to confirm which channel is connected.

Storage, sharing and cookies

  • OAuth access/refresh tokens are stored only locally on the owner's computer. The uploaded video ID and URL are kept in a local log file. Nothing is stored on any server.
  • No data is shared with, sold to or transferred to any third party.
  • The tool does not use cookies or tracking and does not place information on users' devices besides the local token file.

Data deletion and revoking access

  • Access can be revoked at any time on the Google security settings page (myaccount.google.com/permissions).
  • When access is revoked, or on request, the locally stored tokens and logs are deleted within 7 days. Data obtained from YouTube API Services is not kept longer than 30 days unless refreshed.
  • Deletion requests: contact the owner via the e-mail address listed in the Google Cloud project / app developer settings.

Changes

Any changes to this policy will be published on this page with a new effective date.
